# Attribution — Material design icons

The icons in this directory (`ic_brightness_auto_black_18dp`,
`ic_brightness_high_black_18dp`, `ic_brightness_low_black_18dp`, in
Android/iOS/web export densities) are from Google's Material design icons
(https://github.com/google/material-design-icons), licensed under the
Apache License, Version 2.0. The full license text is filed beside this
note as `icons/LICENSE`.

The same three icons are used by the gSwitch app itself in
`gSwitch/Assets.xcassets/ic_brightness_auto.imageset/`,
`gSwitch/Assets.xcassets/ic_brightness_high.imageset/`, and
`gSwitch/Assets.xcassets/ic_brightness_low.imageset/`.
